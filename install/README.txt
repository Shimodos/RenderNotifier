Render Notifier - уведомления о рендере из 3ds Max в Telegram-группу "Viarde Render"

УСТАНОВКА
1. Закройте 3ds Max.
2. Дважды щёлкните Install.cmd в этой папке.
3. Windows спросит разрешение на запуск от имени администратора - нажмите "Да".
4. Дождитесь строки "Done. Restart 3ds Max." и нажмите любую клавишу.
5. Откройте 3ds Max и запустите рендер - сообщения придут в группу.

ОБНОВЛЕНИЕ
То же самое: закрыть 3ds Max, запустить Install.cmd, открыть 3ds Max.

УДАЛЕНИЕ
Закрыть 3ds Max, запустить Uninstall.cmd.

ЕСЛИ СООБЩЕНИЯ НЕ ПРИХОДЯТ
Лог лежит здесь (вставьте в адресную строку Проводника):
%LOCALAPPDATA%\RenderNotifier\render_notifier.log
Нет файла - 3ds Max не загрузил скрипт. Есть - в нём ответ Telegram на каждую отправку.
На компьютере должен быть интернет.

ИМЯ КОМПЬЮТЕРА В СООБЩЕНИЯХ
Задаётся в config\render_notifier.ini, секция [computers]:
ИМЯ_КОМПЬЮТЕРА_В_WINDOWS=значок и подпись
После правки файла - запустить Install.cmd ещё раз.
